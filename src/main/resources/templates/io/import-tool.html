KLTN - Hệ Thống Quản Lý Khách Sạn (Admin)

Công cụ Import Dữ liệu (ETL Tool)

1. Import Tiện Ích (Utility)

Import Master Data (file master_hotel_utility.csv) trước để tạo từ điển hệ thống.

2. Import Khách Sạn (Hotel)

Import các file Khách sạn (hotel.csv) của các thành phố.

3. Import Loại Phòng (Room)

Import danh sách phòng (room_type.csv) theo khách sạn.
